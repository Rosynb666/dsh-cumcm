# 图表与可视化规范

> 目标：图能在**黑白打印**下看懂，在 3 秒内传达一个结论，且能被评委顺手核对。
> 所有图由脚本生成（可复现），统一走 `scripts/figstyle.py`。

## 一、总原则

1. **一图一结论**：这张图想让评委看见什么？说不出来就别画。
2. **自解释**：图题 + 坐标轴 + 单位 + 图例齐了，不看正文也能懂"画的是什么"。
3. **可打印**：黑白复印仍可区分（靠线型/标记/明度，不只靠颜色）。
4. **矢量优先**：导出 PDF；位图仅用于热力图/卫星图，≥300 dpi。
5. **少而准**：全文 8–15 张，每张都在正文被 `\ref` 引用。

## 二、按目的选图型

| 你想说明 | 用这个 | 别用这个 |
|---|---|---|
| 随时间/迭代变化的趋势 | 折线图（线 ≤4 条，超出改分面） | 3D 曲面、面积堆叠过多层 |
| 方案/类别之间的对比 | 条形图（横向，按值排序） | 饼图（>3 类就废）、3D 饼图 |
| 两个变量的关系 | 散点 + 拟合线 + 置信带 | 无拟合的散点堆 |
| 分布与离群 | 箱线图 / 小提琴图 / 直方图 | 只报均值 |
| 相关性矩阵 | 热力图 + colorbar（-1~1 发散色） | 表格里塞满数字 |
| 多指标综合表现 | 雷达图（≤6 维） | 雷达图叠 5 个方案 |
| 预测与不确定性 | 折线 + 阴影置信带 | 只有一条光秃秃的预测线 |
| 灵敏度分析 | 龙卷风图 / 单参数扰动折线 | 一句"结果不敏感" |
| 算法收敛 | 目标值-迭代次数曲线 | 只说"收敛良好" |
| 流程与结构 | 技术路线图 / 流程图（矢量） | 截图拼贴 |
| 空间分布 | 分级设色地图 + 图例 | 无图例的彩色块 |

## 三、版式参数

- 图宽：单图 `0.8\textwidth`，并排小图 `0.48\textwidth`；高度 ≤ 8 cm，避免独占一页。
- 图内字号：与正文同级（约 9–10 pt），**禁止**因为缩图导致字比正文小一半。
- 线宽 1.2–1.5 pt；标记 4–5 pt；网格线浅灰（`#DDDDDD`）、只留主网格。
- 去掉上/右边框（`despine`），去掉背景色块与阴影。
- 坐标轴必须写**量 + 单位**：`时间 t / h`、`成本 / 万元`；无量纲写 `—`。
- 图题格式：`图 3  三种调度方案的日负荷曲线`（编号 + 两个空格 + 是什么），**不写结论**。
- 表题在表上方、图题在图下方；表内数字按小数点对齐，单位写在表头。

## 四、配色

- 4–6 色一组，低饱和、明度拉开；默认用 `figstyle.PALETTE`。
- 顺序色（单指标）用单色系渐变；发散色（有正负/基准）用蓝-白-红。
- **禁用** `jet`/彩虹色（感知不均匀，黑白全糊）、纯红绿搭配（色盲不可辨）。
- 同一含义全文同色（"方案 A"在第 3、7 张图里都是同一个蓝）。

## 五、三线表

```latex
\begin{tabular}{lrr}          % 不要竖线 |
\toprule
方案 & 总成本/万元 & 相对降幅/\% \\   % 单位放表头
\midrule
基准 & 1500.00 & — \\
本文 & \res{cost_total} & \res{cost_drop_pct} \\
\bottomrule
\end{tabular}
```

- 数字右对齐、小数位统一（同一列位数一致）。
- 显著性/最优值用 `\textbf{}` 或脚注说明，不要用颜色（黑白打印会消失）。
- 宽表超过版心就拆表或转置，不要缩小字号硬塞。

## 六、国赛高频扣分点

- [ ] 图注写成结论（`图 4 方案 A 明显优于方案 B`）
- [ ] 坐标轴没单位、没量纲
- [ ] 图里文字太小，打印出来看不清
- [ ] 图表在正文没被引用（"如下图所示"也算引用，但要带编号）
- [ ] 用 Excel 默认配色 + 立体阴影
- [ ] 双 Y 轴滥用（两条曲线强行同图，误导读者）
- [ ] 截断 Y 轴放大差异（误导，评委一眼看出）
- [ ] 热力图没有 colorbar 或范围
- [ ] 图号/表号不连续、跳号
- [ ] 图片是 `.jpg` 截图，放大即糊

## 七、脚本用法

```python
import sys; sys.path.insert(0, "scripts")
from figstyle import apply, save, PALETTE, despine

apply()                       # 中文字体 + 字号 + 线宽 + 去边框，一次到位
fig, ax = plt.subplots(figsize=(7.2, 4.2))
ax.plot(t, y, color=PALETTE[0], lw=1.4, label="方案 A")
ax.set_xlabel("时间 t / h"); ax.set_ylabel("负荷 / MW")
ax.legend(frameon=False); despine(ax)
save(fig, "paper/figs/load_curve.pdf")   # 同时输出 300dpi PNG 便于预览
```

`figstyle` 会在缺 matplotlib 时给出明确报错与替代方案（Pillow 手绘），不静默失败。
